# 現在のゲーム仕様（src/index.html 時点）

## 基本
- iPad の1画面を2人で向かい合って遊ぶエアホッケー。縦横どちらでも、画面の長辺がゴール方向。
- 1P＝下側（赤系）、2P＝上側（青系）。2P側のUIは180°回転して表示。
- 7点先取。ゴール幅は220（v1.29 で 1.1 倍）。マレットは自陣内のみ移動（指に追従、最大速度あり）。
- モード：CPU（よわい／ふつう／つよい）、2P（同一端末）。タイトルの1P側パネルで選択。
- CPU の壁・角の処理：パックが壁や角に張り付いて真後ろに回れないときは、開いている側から壁に向けて叩き、跳ね返りで出す（横の壁＝下向きに当てる、角＝角に向けて当てる、奥の壁＝斜め上に当てる、自陣ゴール前＝横へ払う）。叩いたら跳ね返りの通り道からよける。先読み位置は壁の外に出さない。打てない状態が続いたときは一度突くだけで押し続けない。
- 壁・角に押し付けられたパックはマレットに押されても壁の外に出ない（ゴール口を除く）。重なった分はマレットが押し戻される（以前は角でパックが壁の外に押し出され、ゴール扱いになることがあった）。

## アイテム
- 各プレイヤーの自陣に「?」ボックスが出現（初回4秒後、取得後10秒）。パックを当てると取得（最大2枠）。
- **サーブ後、パックが一度動くまでアイテム関係は停止**（使用不可・ボックスのカウント停止・設置済みの寿命停止）。
- 使用：手元の欄からドラッグ、またはタップで選択→自陣をタッチして設置。
  - 選択した瞬間から **2.5秒の猶予**（スロー0.15倍）。猶予切れでアイテム消滅。残り時間はドットのリング表示。
  - **敵陣には置けない**（相手陣地が赤い斜線で表示、離すと選択状態に戻る）。
  - **選んだアイテムは取り消し・持ち替えできない**（同じ枠に触れると残り時間のままドラッグに戻る。別の枠は使えない）。置くか、猶予切れで消えるまで続く。
- 設置したアイテムの寿命 **9.6秒**（残り2秒で点滅）。1人3個まで（古い順に消える）。

| アイテム | 効果 |
|---|---|
| ジャンプ台 | 進行方向はそのまま速さ1.1倍（最低380、上限1760）で1.25秒間空中へ。空中はマレット・床アイテムをすり抜ける。着地点に照準表示 |
| 加速床 | 相手ゴール中央へ向く（真正面±30°まで）。乗った瞬間に床の向きへスナップして射出（max(速さ×1.25,1280)、上限2080） |
| バンパー | 1.25倍反発。止まったパックも外へ弾く。**空中のパックも跳ね返す** |
| ぬかるみ | 進入時に速さ40%、内部で強く減速（上限304）。マレットも40%速度 |
| スーパーシュート（キノコ） | **タップで即使用**（置かない）。自機が青いオーラの強化状態に。強化中にパックへ触れるとスロー＋パック停止 → 指を引っ張って狙い、離すと引っ張りの逆方向へ加速床の最高速（2080）で発射（2.5秒で自動発射）。発射・得点で強化解除。スーパーシュートのパックは設置物を壊す（バンパー・スライムは効果のあと、加速床は効果なしで壊れる。ジャンプ台は壊れない）。構え中、撃つ側のマレットは動かない（狙いは指の位置で決まる）。**守る側は40%の速さで動ける**（止まっているパックの96以内には近づけない）。CPU は守る人のいない側を狙う。青いオーラのパックに触れた相手のマレットは1.5秒スタン（動けない）し、パックは減速して遅く（336）、必ず打った側のコートへ跳ね返る（打った側のチャンス）。撃った本人のマレットは発射直後0.25秒は当たらない |

## パックの速さ（v1.37〜）
- 速さの値は「旧ゲームスピード0.8倍」を基準（100%）に書き直した（旧値の0.8倍。最高速 1680、強打の判定 1480、加速床・スーパーシュート 2080 など）。パックの時間に関わる値（空中時間・加速の時間）は1.25倍、摩擦は0.8倍。
- OPTION の **PUCK SPEED**（50〜150%）はパックの動き（移動・減速・空中時間・加速）だけに掛かる。タイマー（4秒ルール・アイテムの寿命・ボックス・スタン・構え・パリィ停止）、マレット、CPU は実時間のまま。

## 盤面
- 四隅は半径64の丸い角（レールと同じ色の階段状ブロック）。パック・マレットとも角の円の内側にとどまり、角に挟まらない。
- ゴール口の両端に白いゴールポスト。当たると光り、金属音と火花。

## パリィ
- パックが自分のマレットに当たる直前、受付時間（標準 0.1 秒＝100ms）以内に指を離していたら成立（オンラインのゲストは +0.03 秒）。強化中は成立しない（スーパーシュートの構えが優先）。CPU は使わない。
- さらに次の2つを満たすときだけ成立：①直前にパックに触ったのが自分ではない（相手の打球・相手のスーパーシュート/パリィ、サーブ後まだ誰も触っていないパックは可。自分の打球が戻ってきたものは不可）②当たる瞬間のパックの速さが下限（標準 800）以上。
- 止まる時間（標準 1 秒）だけパック・タイマーが止まる。パリィした人は動かず、**相手は40%の速さで動ける**（狙いの点線は相手にも見える）。受付時間・止まる時間・速さの下限は開発者画面で変更でき端末に保存、実時間で数えるのでパックの速さ設定とは独立。オンラインはホストの値。成立時に「キュイーン」と上がっていく音。狙い方はスーパーシュートと同じ：止まっている間に自分の側に指を置いて引っ張り、離すと引っ張りの逆方向へ弾く（時間切れはその時の向き、指を置かなければ普通に跳ね返る向き）。速さは来た速さの1.2倍（1728〜2080）。目標速度の0.45倍から0.22秒でなめらかに加速する。
- 弾いたパックにはパリィした側のフィールドの色のオーラ（縁取りのグラデーション）。次に誰かが触れる・遅くなる（560未満）・2秒で消える。
- スーパーシュートのパックもパリィで返せる（スタンしない）。
- **早すぎの合図**：パリィを狙ったらしいが早く離しすぎたとき（相手の速い球が、受付時間を過ぎてから0.3秒以内に当たった。受付時間の設定を変えても同じ幅で出る）は、「ブッブー」という2音と、マレットの周りで割れて散る灰色の輪、マレットの上に浮かぶ「EARLY」の文字（その人の向き、打撃のエフェクトより上）で知らせる。FX LEVEL が MIN でも出る。

## 特殊ルール
- **自陣で4秒**パックがとどまると爆発し、相手に1点。残り3秒からリング＋秒数＋パック赤明滅＋警告音。
- 端の壁際でパックが1.2秒止まると内側へ押し出し。
- ゴール後は失点側からサーブ。

## OPTION（テーマ）
- PUCK：CLASSIC / GOLD / NEON / RUBY / SHADOW
- FIELD：CLASSIC / SUNSET / JUNGLE / OCEAN / MONO（陣地・レール・マレット・UIの色）
- FX STYLE：ARCADE / KAWAII / WEB90 / CLAUDE（吹き出し・考え中の「…」・＊のキラキラ。impact・smash・goal だけ専用のドット絵、他は ARCADE と同じ）（90年代Web風を抽象化：立体ボタンの縁〔左上が白・右下が灰〕、点線〔マーチングアンツ〕、細い虹のライン、小さなキラキラだけで表現し、数・大きさ・表示時間を抑えた控えめな演出。虹・キラキラの色は FX COLOR に従う）。STYLE が変えるのは全エフェクト・盤面の縁の電飾・パックの軌跡・アイテム選択中のスロー演出・GOAL!! の装飾。アイテム設置のゴースト／残り時間リング／敵陣の斜線／着地点マーク／4秒カウントは全STYLE共通
- FX COLOR：ARCADE / NEON / MONO / PASTEL / CANDY / DIGITAL（白 #FFFFFF・青 #0000FF・灰 #8A8883 の3色基調） / CLAUDE（テラコッタ系オレンジ・クリーム・ウォームグレーの暖色）
- FX LEVEL：FULL / LITE / MIN
- 選択は localStorage（キー `ah_theme`）に保存。**テーマは各端末ローカル**（オンラインでも同期しない）。

## エフェクトの種類（v1.23〜 8種類）
どの FX STYLE もこの8種を描く。場面ごとに原則1〜2種。

| 種類 | 役割 | 主な場面 |
|---|---|---|
| impact | 当たった点で弾ける（壁向き・小さな火花の変化あり） | 打撃・壁・高速時の火花・爆発・着地・スーパーシュート |
| wave | 広がる輪郭 | 強い打撃・バンパー・設置・取得・ジャンプ台・爆発・スタン |
| smash | 強打 | スマッシュ |
| speed | 向きのある流線 | 加速床・ジャンプ台・スーパーシュート発射 |
| mud | ぬかるみ（入る／出る／泡／しずく） | ぬかるみ |
| goal | ゴール演出（大きな演出＋紙吹雪） | ゴール |
| spawn | アイテムボックス出現 | ボックス出現 |
| fly | 取ったアイテムが欄へ飛ぶ | アイテム取得 |

- smash は FX STYLE ごとのドット絵アニメ（`tools/smash_gen.py`、7コマ×8方向）。ARCADE＝ギザギザの爆発星と速度線、KAWAII＝つや付きの星とハート、WEB90＝立体ボタンの縁と細い虹。
- ARCADE の impact は `tools/impact_gen.py` で作ったドット絵アニメ（6コマ）。色はパレット番号で持ち、FX COLOR で着色。
- 擬音（文字のエフェクト）は廃止。
- LITE：speed・spawn・ぬかるみの泡/しずく・小さな火花は出さない。MIN：fly とヒットストップの点だけ。

## 表示方針
- 説明文なし。文字の擬音エフェクトは全モード無効。
- 残す文字：スコア、GOAL!!、勝敗パネル、持ちすぎ警告の秒数。

## ボス「NULL」（v1.41〜、タイトルの CPU の横の巻物ボタン）
- プレイヤーの技とルールを盗んで使うボス。1人用（CPU 戦の仕組みの上に作る。オンラインには影響しない）。
- **ボス戦では、加速床を通った球・バンパーで跳ね返った球は「だれの球でもない」扱い**になり、自分の打った球が戻ってきてもパリィできる（ボスのツイン加速ショットの床は除く）。
- プレイヤーがパリィすると、ボスは0.5秒遅れて動き出す（時間停止の最初の0.5秒は止まったまま）。
- ボスのマレットの動き（速さ・反応・狙いのずれ）は CPU「ふつう」と同じ。強さは技で出す。ツイン加速ショットの前兆中は、打たずに球の後ろで待つ。
- **HP10**：プレイヤーのゴール1点で1減る。**パリィで返した球のゴールは2**。プレイヤーは**ライフ5**（ボスのゴールで1減る、下の帯に表示）。
- **前兆**：技はすべて、ボス陣地の右上の「次の技ボックス」で分かる（いつも次の技の絵を表示、使う1秒前に光って揺れ、中央に技の名前）。順番は段階ごとに決まっている。
- 第1段階「コピー」（HP10〜7）
  - **ツイン加速ショット**：加速床を2枚並べて、その上を通す超高速球（最高速）。パリィで返すとボスが1.5秒ひるむ。登場直後に必ず1回目を撃ち、「当たる直前に指を離すとパリィ！」と出す。
  - **メガバンパー**：ボスのゴール前にバンパー3つ（各耐久2）。**パリィで返した球・加速ショット（加速床を通った球）なら一発で壊れる**。スーパーシュートも壊す。全部壊すとボスが2.5秒ひるむ。**壁が1つでも残っている間は次のメガバンパーを出さない**（重ならない）。
- 第2段階「強奪」（HP6〜4）
  - **パリィの構え**：ボスのマレットが白く光る間（約2.6秒）、正面からの強打（速さ800以上）はパリィで返される。角度のある球・遅い球は空振りでボスが2秒止まる。
  - **スーパーシュート**：ボスが青いオーラで構える（守る側は40%で動ける）。パリィで返すとボスがひるむ。
  - **アイテムどろぼう**：プレイヤーのボックスに赤いリング（2.5秒）。それまでに取れなければボスに奪われ、ボスが使う。
  - ツイン加速ショットも使う。
- 最終段階「越境」（HP3〜1）：メタ技。切り替わるとき、開発者画面の形で「PUCK SPEED 100%→130%」「HOLD(1P) 4.0s→2.0s」と書き換えて見せる。書き換えは上の帯に表示し続け、**プレイヤーがゴールを決めるたびに1つ戻る**。
  - **ゴールの壁を壊す**：プレイヤー側（下）のゴールの両脇の壁を壊し、ゴールが60広がる（最大+120）。
  - **とっしん**：2.2秒、ボスが中央線を越えてパックを追う（ボスのゴールはがら空き）。
  - **アイテム欄を壊す**：プレイヤーのアイテム欄の1つを5秒使えなくする（ひびと残り秒）。
  - スーパーシュート・パリィの構えも使う。
  - **HP1**：盤面が傾き、パックがプレイヤーのゴール側へ流れる。同時にアイテム欄に **RESTORE** が届く（タップで使用）。書き換え・壁・傾き・欄のひびを全部元に戻し、ボスが3.5秒止まる。
- **負けたら**：「つづきから」で今の段階の最初（HP10／6／3）からすぐ再開。同じ段階で2回以上負けたら、ライフ+2。
- **撃破**：大きく止めて光り、書き換えた項目が1つずつ RESET されて「RULE RESTORED」。タイム・パリィ回数・パリィゴール回数を表示し、ベストタイムを保存（タイトルの巻物ボタンに ★）。
- 調整値は `BOSSC`（HP・ライフ・パリィゴールのダメージ・ひるみ・前兆の長さ・壁の耐久・書き換え後の速さ・広がる幅・傾き・とっしん・欄の壊れる時間・どろぼうの時間）。

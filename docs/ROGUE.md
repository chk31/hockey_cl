# ローグライク版（v1.59〜、v1.60 で敵のアイテム・強化と重ねがけ、v1.61 でエンドレス・パリィのスタン）

公開URL：`https://chk31.github.io/hockey_cl/rogue/`（ふつうのモードは今までどおり `https://chk31.github.io/hockey_cl/`）

## 作り（案1：コアは共有）
- 本体 `site/index.html` はそのまま。ローグライクの部分は `site/rogue/rogue.js` だけに書く。
- 公開時（`.github/workflows/pages.yml`）に `tools/build_rogue.py` が本体をコピーし、
  本体のスクリプト（全体が `{ … }` で囲まれている）の内側の最後に `rogue.js` を埋め込んで `site/rogue/index.html` を作る。
  `<base href="../">` で画像などは本体と同じ物を使い、manifest（ホーム画面の名前 `HOCKEY ROGUE`）だけ `site/rogue/manifest.webmanifest`。
  作られる `site/rogue/index.html` はリポジトリに入れない（`.gitignore`）。手元で確かめるときは `python3 tools/build_rogue.py`。
- 本体を直すとローグライク版にも同時に入る。版の番号・自動更新も本体と同じ。
- 本体側に足したのは「何もしなければ今と同じ」差し込み口だけ：`RULE.win`（勝ちの点数）、プレイヤーごとの `P[i].mr / hm / boxK / lifeK / parK / iw`、上のゴールの広げ幅 `WB.t`、ボスの段階の境目 `BOSSC.ph2 / ph3`。
- `rogue.js` は本体の関数 `goal / update / pdown / drawAll / parryStart / give` を包み直して流れを足す。

## 流れ（最小構成）
- **アイテム欄は試合をまたいで持ち越す**（v1.64〜。RESTORE だけは持ち越さない）。
- タイトル（ROGUE）→ 戦1 ザコ → 3枚から1枚 → 戦2 強敵 → 3枚から1枚 → 戦3 ボス NULL → 3枚から1枚 → **エンドレス**。負けたらその場で終わり。中断と再開はなし。
- **エンドレス**（v1.61〜）：ザコ → 強敵 → 3枚から1枚 を1周（LOOP）として繰り返す。1周ごとに戦力ポイントの予算が増える（下の「敵」）。紹介画面に ENDLESS LOOP n、相手のトレイに LOOP n。
- **パリィ**（v1.61〜、ローグのみ）：時間停止が終わったあと、敵（ザコ・強敵・NULL）は 0.3 秒スタン。NULL のパリィ球のゴールは1点（本体のボス戦は2点のまま）。
- **各試合はお互い HP3**（3点取られたら負け）。トレイの点数の所にハートで出す。ボスも HP3（2で第2段階、1で最終段階＝台が傾く・RESTORE）・プレイヤーのライフ3。
- **スタート時にパークをランダムに1つ持って始まる**（v1.62〜）。最初の紹介画面に「START：〜」と出る。
- 試合の前に2秒、相手の名前と技を見せる（タップで飛ばせる）。
- 記録：NULL を倒した回数・最高 LOOP・最多勝利数（端末に保存 `ah_rogue`）。

## 敵（v1.64〜 戦力ポイントで組み立て）
試合ごとに予算 B（戦力ポイント）を決め、「基礎の動き d・強化パーク・技・技の強化」に割り振って相手を組み立てる。プレイヤーの強さによる補正はしない。

| 部品 | コスト |
|---|---|
| 基礎の動き d（0＝よわい、1＝ふつう、2＝つよい の数値を混ぜる。速さだけは「つよい」の半分まで） | 10 × d |
| ハードショット／ビッグマレット | 3 / Lv（上限 Lv4／Lv3） |
| ワイドゴール | 4 / Lv（上限 Lv3） |
| 長持ち（JUMPER の時だけ） | 1 / Lv（上限 Lv3） |
| 技 JUMPER／BLOCKER／CHARGER | 3／4／5 |
| 技の強化（間隔 ×0.8・バンパー耐久 +1 を1段ごと） | 1 / 段（上限3） |

数値のくせ（コスト0）：スピード型（速さ+20%・ずれ+30%）、精密型（ずれ−40%・速さ−15%）、強打型（打つ力+0.2・追いかけ−0.1）、守備型（追いかけ+0.15・反応−10%・打つ力−0.1）。

- **ザコ**：予算＝4×周回（最初のザコは 0＝純粋な「よわい」）。70% 以上を基礎の動きに。残りはステータス系パーク1種類だけ（重ねがけ可）。技なし。くせはランダム（最初のザコはなし）。
- **強敵**：予算＝6＋5×周回。技を1つ必ず → 2周目から技の強化（残りの1/8ほど）→ 残りの 40〜60% を基礎の動き → 残りは技と相性のよいパーク（JUMPER→ハード・長持ち、BLOCKER→ビッグ、CHARGER→ハード を6割で優先）。使い切れない分は d へ。くせは技に合わせる（JUMPER＝スピード、BLOCKER＝守備、CHARGER＝強打）。
- 予算の上限は 60。上限やパーク・d の上限で使い切れない分は使わない（例：12周目のザコは P32 で頭打ち）。
- **強さ（POWER）**＝50×1.0923^P（10の位で丸め、P＝使った戦力ポイント、P60 で 10000）。最初のザコ 50、最初の強敵 80、2周目の強敵 210、4周目 500、6周目 1200。ボス NULL は P25 固定（450）。
  色：〜99 白、〜499 黄、〜1999 橙、2000〜 赤の点滅。
- 表示：試合前の紹介画面に POWER と、技・動きの強さ・くせ、敵のパーク（＋技の強化）のアイコン。プレイ中は相手のトレイに `PWR n`（ボス戦は自分側のトレイの下）。パーク一覧の ENEMY 欄に POWER・P・内訳。
- **パリィの時間停止中は CPU は完全に止まる**（v1.63〜。本体の CPU 戦は守る側が 40% で動けるまま）。

強敵の技（どれも 0.8 秒前に「！」と印で前兆）：
- **JUMPER**：10秒ごとに、自分の陣地へジャンプ台を置く。
- **BLOCKER**：ゴールの前にかたいバンパー（耐久3、パリィ球・加速球なら一発）。壊すと CPU が少しひるみ、15秒後に置き直す。
- **CHARGER**：15秒ごとに強化（次に触ったらスーパーシュート）。

## パッシブ（10個、持てるのは2つ。3つ目を取ると一番古いものと入れかわる）
- **ステータスアップ系（ハードショット・ビッグマレット・ワイドゴール・箱の常連・長持ち）は重ねがけできる**（v1.60〜）。持っている物のカードは「Lv2 UP」と出て、取ると枠を使わずに Lv が上がる（アイコンの右下に数字）。入れかわりで外れると Lv も消える。
  重ねたときの効き：打つ速さ 1+0.12×Lv 倍／マレット 1+0.25×Lv 倍／ゴール 左右に 20×Lv（最大126）／箱の間隔 0.65^Lv 倍／置いた物 1+0.6×Lv 倍。
- それ以外（ひいき・後の先・ギリギリ王）は1つだけ。持っていれば出ない。
| 名前 | 効果 |
|---|---|
| ハードショット | 打ったパックが 12% 速い |
| ビッグマレット | マレットが 1.25倍 |
| ワイドゴール | 相手のゴールが左右に20ずつ広い |
| 箱の常連 | アイテム箱の間隔 ×0.65 |
| 長持ち | 置いた物の持続 ×1.6 |
| ひいき | カードに出たアイテム1種が3倍出やすい |
| 後の先 | パリィに成功するとアイテム箱がすぐ出る |
| ギリギリ王 | パリィの受付が半分、成功すると次の自分の得点が2点（×2 表示） |
| 残心（重ねがけ可） | パリィ後の敵のスタンが 0.2 秒×Lv 長い |
| つらぬき（重ねがけ可） | パリィで返した球に当たった敵が 0.3 秒×Lv スタン |

試合中は自分のトレイの右に持っているパッシブのアイコン。効いた瞬間に光る。
- **パーク一覧**（v1.63〜）：試合中に自分のトレイのパークのアイコンを触る、または報酬の画面の PERKS ボタンで開く。自分のパーク（Lv と今の効き）と、相手の強化を一覧で出す。開いている間は試合が止まり、タップで戻る。
- **ひいき**のアイコン・カードの色は、よく出るアイテムの色（ジャンプ台＝橙、加速床＝水色、バンパー＝紫、ぬかるみ＝緑）。

## 開発者用サンドボックス（左上の SB）
プレイ中も開いたまま状態を変えられる（パネルの上のタッチはゲームに届かない）。
- **戦力**：今の相手の POWER と P、予算 P を指定して組み直す、動き d の上書き、各コスト・予算の伸び・上限・NULL の P。
- **RUN**：パーク一覧、ザコ戦／強敵戦／ボス戦をすぐ始める、新しいラン、タイトル、いま勝ち／いま負け、報酬を引く（v1.62〜：試合は続いたまま、パークだけもらって今の試合に戻る）、自分／相手の HP 無限（点を取られても減らない。ボス戦はライフ・ボスの HP）、エンドレスへ、周回 LOOP の数、パリィ後の敵スタンの秒数。
- **HP**：試合ごとの HP、自分／相手の今の HP（ボス戦はライフ・ボスの HP）。
- **PASSIVE**：8個を自由にオン・オフ（今の試合にもすぐ反映）、ステータスアップ系の Lv、ひいきのアイテム。
- **敵の強化**：敵のパッシブ（4種）のオン・オフと Lv、「ザコ・強敵は箱なし」の切り替え。
- **自分の数値（上書き）**：マレット半径・打つ速さ・箱の間隔・置物の持続・パリィ受付の倍率、相手ゴールの広げ幅。上書きは次の試合にも残る（「上書きを消す」で戻す）。
- **相手 CPU の数値**：速さ・反応・狙いのずれ・アイテム間隔・打つ力・追いかけ（次の試合にも残る）。
- **強敵の技**：3つを自由に付け外し（どの戦でも）、今すぐ発動、間隔・耐久・前兆の時間。
- **アイテム**：自分／CPU にアイテムを渡す、箱を出す、置いた物を消す、自分を強化。
- **世界**：一時停止、スロー ×0.25、パックを中央へ、パックの速さ、パリィの受付・停止時間。
- **ボス**：技を今すぐ使わせる、段階を変える。

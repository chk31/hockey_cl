- 本体 `site/index.html` はそのまま。ローグライクの部分は `site/rogue/rogue.js` だけに書く。

## 流れ（最小構成）
- **アイテム欄は試合をまたいで持ち越す**（v1.64〜。RESTORE だけは持ち越さない）。
- タイトル（ROGUE）→ 戦1 ザコ → 3枚から1枚 → 戦2 強敵 → 3枚から1枚 → 戦3 ボス NULL → 3枚から1枚 → **エンドレス**。負けたらその場で終わり。中断と再開はなし。
- **エンドレス**（v1.61〜）：ザコ → 強敵 → 3枚から1枚 を1周（LOOP）として繰り返す。1周ごとに戦力ポイントの予算が増える（下の「敵」）。紹介画面に ENDLESS LOOP n、相手のトレイに LOOP n。
- **パリィ**（v1.61〜、ローグのみ）：時間停止が終わったあと、敵（ザコ・強敵・NULL）は 0.3 秒スタン。NULL のパリィ球のゴールは1点（本体のボス戦は2点のまま）。
- **得点システム（v1.68〜）**：敵は点数の代わりに **HP**（最初のザコ100・強敵180・NULL 600。エンドレスは5周目まで ×1.35／周、6周目から ×2.2／周）。**ダメージ ＝ C ×（1＋トリック）× ラリー倍率 ×（パークの倍率）**。自分は **ライフ7**（敵のゴールで −1、報酬で +2、NULL のあとは全回復）。詳しくは `docs/ROGUE_SCORE.md`。NULL は HP 600 を 66%・33% で段階分け（最終段階で台が傾く・RESTORE）。
- **スタート時にパークをランダムに1つ持って始まる**（v1.62〜）。最初の紹介画面に「START：〜」と出る。
- 試合の前に2秒、相手の名前と技を見せる（タップで飛ばせる）。
- 記録：NULL を倒した回数・最高 LOOP・最多勝利数（端末に保存 `ah_rogue`）。

## チャクラ（得点）
- **バトルの結果画面**（v1.70〜）：ゴール1本ごとに、ショット（弱打・打撃・強打・速打・SMASH・PARRY・SUPER・加速床・ジャンプ台・バンパー・4秒爆発）・C・T・ダメージ・トリックの加算・計算で発動したパークを一覧で出す。
- **C**：自分のマレット・自分の加速床／ジャンプ台／バンパー・パリィ・スーパーに当たるたびに上書き（敵が触っても残る）。打撃 10／20／30／40、スマッシュ 60、パリィ 80、スーパー 100。色（砥石ゲージ）は赤→橙→黄→緑→青→白→紫。C は周回では伸びない（v1.74 で研ぎを廃止）。
- **トリック値 T**（v1.70〜）：T＝（1＋各種加算）×ラリー倍率。加算は、バンク +0.2（2回以上 +0.4）・ポスト +0.5・空中 +0.3・ロング +0.2 に加えて、1ラウンド中の「敵がスタンした回数 +0.1」「壁に当たった回数 +0.01」「アイテムを使った回数 +0.05」「パリィ・スマッシュした回数 +0.05」（壁・スマッシュの回数カウントは 0.3秒のクールタイムつき）、爆発 +0.3、敵がスタン中のゴール +0.3、GUARD BREAK 中のゴール +0.4。ダメージ＝C×T。ラリー倍率は 1＋0.1×往復（上限 ×3）。**最低ダメージ**は敵の最大 HP の 8%。4秒ルールの爆発は C そのまま（最低 20）。
- **表示**：パックは C の色で、枠は黄色固定・一番上のレイヤー。トリックが乗っている間は枠のまわりに印。C が上書きされるたびに小さな輪、色の段階が上がったときは「C 60」。ゴールで内訳と合計、桁（1K・1M…）を初めて超えたときは演出。数字は 12.3K／4.56M／…／aa 表記。
- **パーク**：チャクラ系 18 個（＋C系・×倍率系・トリック系・発動系・レア3つ）。報酬の1枚は必ず＋C か×倍率系。

## 敵の動きの強さと耐久力（v1.69〜）
- **動きの強さ d は試合の番号で決まる曲線**（戦力の予算とは別。予算の残りは HP・パーク・技に回る）。最初のザコ＝0（「よわい」より弱い専用の基準：速さ 480・反応 0.48・狙いのずれ 105）→ 試合の番号 ÷ 13 で上がり、**6周目の強敵（13試合目）で d=1＝「ふつう」**。そのあとは26試合かけて「つよい」まで。表示名：とてもよわい／よわい／ややよわい／ふつう／ややつよい／つよい。
- **マレットの最高速は敵味方とも ×0.9**（自分 3400→3060、CPU は強さの値の 0.9 倍）。ボス NULL にも掛かる。
- **敵のマレットの耐久力（GUARD）**：敵のマレットがパックから受けた C（接触の瞬間の C）をたくわえ、耐久力を超えると **4秒スタン**して 0 に戻る（スタン中は積まない）。耐久力＝300 ×（戦力ポイントの強さ÷50）^0.6（最初のザコ 300、最初の強敵 387、6周目の強敵 約 1400）。C が高い・長く打ち合うほど早く割れる。上の帯の HP ゲージの下に青い耐久ゲージ（満タンに近づくと点滅）、割れると「GUARD BREAK」。

## 敵（v1.64〜 戦力ポイントで組み立て）
試合ごとに予算 B（戦力ポイント）を決め、「基礎の動き d・強化パーク・技・技の強化」に割り振って相手を組み立てる。プレイヤーの強さによる補正はしない。

| 部品 | コスト |
|---|---|
| 基礎の動き d（0＝よわい、1＝ふつう、2＝つよい の数値を混ぜる。速さだけは「つよい」の半分まで） | 10 × d |
| ハードショット／ビッグマレット | 3 / Lv（上限 Lv4／Lv3） |
| ワイドゴール | 4 / Lv（上限 Lv3） |
| 長持ち（JUMPER の時だけ） | 1 / Lv（上限 Lv3） |
| 技 JUMPER／BLOCKER／CHARGER | 3／4／5 |
| 技の強化（間隔 ×0.8・バンパー耐久 +1 を1段ごと） | 1 / 段（上限3） |

数値のくせ（コスト0）：スピード型（速さ+20%・ずれ+30%）、精密型（ずれ−40%・速さ−15%）、強打型（打つ力+0.2・追いかけ−0.1）、守備型（追いかけ+0.15・反応−10%・打つ力−0.1）。

- **ザコ**：予算＝4×周回。動き d は上の曲線で、予算の残りの半分で HP を買い、残りはステータス系パーク1種類（重ねがけ可）。技なし。くせはランダム（最初のザコはなし）。
- **強敵**：予算＝6＋5×周回。技を1つ必ず → 2周目から技の強化（残りの1/8ほど）→ 余りの3割で HP → 残りは技と相性のよいパーク（JUMPER→ハード・長持ち、BLOCKER→ビッグ、CHARGER→ハード を6割で優先）。使い切れない分は d へ。くせは技に合わせる（JUMPER＝スピード、BLOCKER＝守備、CHARGER＝強打）。
- 予算の上限は 60。上限やパーク・d の上限で使い切れない分は使わない（例：12周目のザコは P32 で頭打ち）。
- **強さ（POWER）**＝50×1.0923^P（10の位で丸め、P＝使った戦力ポイント、P60 で 10000）。最初のザコ 50、最初の強敵 80、2周目の強敵 210、4周目 500、6周目 1200。ボス NULL は P25 固定（450）。
  色：〜99 白、〜499 黄、〜1999 橙、2000〜 赤の点滅。
- 表示：試合前の紹介画面に POWER と、技・動きの強さ・くせ、敵のパーク（＋技の強化）のアイコン。プレイ中は相手のトレイに `PWR n`（ボス戦は自分側のトレイの下）。パーク一覧の ENEMY 欄に POWER・P・内訳。
- **パリィの時間停止中は CPU は完全に止まる**（v1.63〜。本体の CPU 戦は守る側が 40% で動けるまま）。

強敵の技（どれも 0.8 秒前に「！」と印で前兆）：
- **JUMPER**：10秒ごとに、自分の陣地へジャンプ台を置く（赤い色違い。入ってきた向きのまま跳ぶ）。
- **BLOCKER**：ゴールの前にかたいバンパー（耐久3、パリィ球・加速球なら一発）。壊すと CPU が少しひるみ、15秒後に置き直す。
- **CHARGER**：15秒ごとに強化（次に触ったらスーパーシュート）。

## パッシブ（ふつう11個＋レア2個。v1.65〜 数の制限なし）
- **ステータスアップ系（ハードショット・ビッグマレット・ワイドゴール・箱の常連・長持ち・残心・つらぬき・ジャンプ台・パリィホーミング）は重ねがけできる**。持っている物のカードは「Lv2 UP」と出て、取ると Lv が上がる（アイコンの右下に数字）。
  重ねたときの効き：打つ速さ 1+0.12×Lv 倍／マレット 1+0.25×Lv 倍／ゴール 左右に 20×Lv（最大126）／箱の間隔 0.65^Lv 倍／置いた物 1+0.6×Lv 倍。
- それ以外（ひいき・後の先・ギリギリ王・アイテム枠 +1）は1つだけ。持っていれば出ない。スタート時のパークはレア以外から。
| 名前 | 効果 |
|---|---|
| ハードショット | 打ったパックが 12% 速い |
| ビッグマレット | マレットが 1.25倍 |
| ワイドゴール | 相手のゴールが左右に20ずつ広い |
| 箱の常連 | アイテム箱の間隔 ×0.65 |
| 長持ち | 置いた物の持続 ×1.6 |
| ひいき | カードに出たアイテム1種が3倍出やすい |
| 後の先 | パリィに成功するとアイテム箱がすぐ出る |
| ギリギリ王 | パリィの受付が半分、成功すると次の自分の得点が2点（×2 表示） |
| 残心（重ねがけ可） | パリィ後の敵のスタンが 0.2 秒×Lv 長い |
| つらぬき（重ねがけ可） | パリィで返した球に当たった敵が 0.3 秒×Lv スタン |
| ジャンプ台（重ねがけ可、v1.65〜） | ローグ版ではジャンプ台はふつう出ない。このパークで出るようになり、重ねるほど出やすい（出やすさ 5→8→11→14、ほかのアイテムは5） |
| **RARE** パリィホーミング（重ねがけ可） | パリィで返した球が相手のゴールへ曲がる（1秒に 2.4 ラジアン×Lv、速さはそのまま）。**Lv2 以上は敵やアイテムで跳ね返ったあとも 3 秒まで曲がり続ける**（自分が触るか点が入ると終わる。v1.67〜） |
| **RARE** アイテム枠 +1 | アイテム欄が3つ（少し細く詰めて並べる） |

- **ジャンプ台の向き**（v1.65〜、ローグのみ）：ジャンプ台は必ず置いた人の相手側（相手のゴールの方、真正面から±30°まで）へ飛ばす。台の上に向きを示す流れる点を出す。強敵 JUMPER のジャンプ台は**向きなし（本体と同じ性能）・赤い色違い**（v1.66〜。向きを付けると強すぎたため）。
- **レアパーク**：ふつうの報酬では、カード1枚ごとに 10% でレアになる（金とピンクに点滅する枠、RARE の表示）。**NULL を倒したあとの報酬は「レア1つ」か「ランダム2つ（中身は見える）」のどちらか**。
- 自分のトレイのパークのアイコンは、数が多いと小さく並べる（12個まで、それ以上は +n）。

試合中は自分のトレイの右に持っているパッシブのアイコン。効いた瞬間に光る。
- **パーク図鑑**（v1.67〜）：ローグのタイトルの「パーク図鑑」で、実装済みのパークをすべて（ノーマル／レア、説明と Lv1・Lv2 の効き、ランの途中なら「所持」）見られる。ページ送りつき。
- **パーク一覧**（v1.63〜）：試合中に自分のトレイのパークのアイコンを触る、または報酬の画面の PERKS ボタンで開く。自分のパーク（Lv と今の効き）と、相手の強化を一覧で出す。開いている間は試合が止まる。多いときは「まえ／つぎ」でページ送り、「もどる」で戻る。
- **ひいき**のアイコン・カードの色は、よく出るアイテムの色（ジャンプ台＝橙、加速床＝水色、バンパー＝紫、ぬかるみ＝緑）。

- **戦力**：今の相手の POWER と P、予算 P を指定して組み直す、動き d の上書き、各コスト・予算の伸び・上限・NULL の P。

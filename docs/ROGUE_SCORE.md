# ローグ版 得点システム（チャクラ）— v1.68 で実装、v1.70 でトリック値に統一

実装は `site/rogue/rogue.js` の「得点システム（チャクラ）」（`SC`＝調整値）。開発者メニュー（SB）の「チャクラ（得点）」から全部変えられる。表の数値はそのまま初期値。

ローグ版（`/rogue/`）だけの変更。ふつうのモードは変えない。数値はすべて開発者メニューから変えられるようにする（【】が調整値）。

## 0. v1.70 の変更（トリック値への統一）
- **ダメージ ＝ C × T**。**T（トリック値）＝（1 ＋ 各種加算）× ラリー倍率**（ラリー倍率は T の内部計算の最後に掛ける）。
- 加算するもの：今までのトリック（バンク・ポスト・空中・ロング・速攻）に加えて、**1ラウンド（サーブからゴールまで）の動きを全部**入れる。数値はすべて調整値（`SC.tr`）。

| 加算 | 値 |
|---|---|
| 敵がスタンした回数（パリィ・つらぬき・GUARD BREAK・スーパーを受けたとき） | 1回 +0.1 |
| 壁に当たった回数（速さ200以上） | 1回 +0.01 |
| アイテムを使った回数（置いた・スーパーを構えた） | 1回 +0.05 |
| パリィした回数 | 1回 +0.05 |
| スマッシュした回数 | 1回 +0.05 |
| 4秒ルールの爆発 | +0.3 |
| 敵がスタン中のゴール | +0.3 |
| 敵が GUARD BREAK 中のゴール | +0.4（スタン中と重ならない） |

- **回数カウントのクールタイム**（v1.74〜）：壁・スマッシュのカウントは、接触イベントの連射を数えないよう【0.3秒】のクールタイムつき（`SC.ccd`、開発者メニューで変更可）。C の更新自体は毎ヒット従来どおり。

- ×系パーク（紫電・増幅・虹・ギリギリ王の ×2・長期戦の ×0.85）は、**C を N 倍したものとして表示**する（「C 60 ×1.6（紫電）→ 96」）。計算は同じ。
- 4秒ルールの爆発は、C（最低 20）× T（爆発 +0.3 を含む）で、ふつうのゴールと同じ式になった。
- **バトルの結果**：ゴール1本ごとに、ショットの種類・C（×系を掛けたあと）・T・ダメージ・T の中身（トリックの加算）・C の倍率・計算で発動したパークのアイコンを表示する（8本まで。多いときは上位8本）。

## 1. 基本
- 敵は点数の代わりに **HP** を持つ。削り切ったら勝ち。
- 自分は **ライフ制**：最初 7、上限 7、敵のゴールで必ず −1、報酬のたびに +2、NULL を倒したら全回復。0 で終わり。
- **ダメージ ＝ C ×（1 ＋ トリック値の合計）× ラリー倍率 ×（×系パークの積）**
  - Balatro の「チップ × 倍率」：C がチップ、トリック値とラリーが倍率（加算）、×系パークが倍率（乗算）。
- **最低ダメージ**：1本で必ず敵の最大 HP の【8%】以上（噛み合わないビルドでも 13 本以内に終わる）。

## 2. C（チャクラ）
- 自分のマレット・自分のアイテム（加速床・ジャンプ台・バンパー）に当たるたびに **上書き**。敵が触っても残る。
- 基本値（v1.74 で研ぎは廃止。C は周回では伸びない。伸びはパークで作る）

| 当たり方 | C |
|---|---|
| 打撃 弱（速さ <300）／中（〜700）／強（〜1100）／速（〜1480） | 10 ／ 20 ／ 30 ／ 40 |
| スマッシュ | 60 |
| パリィ | 80 |
| スーパーシュート | 100 |
| 自分の加速床／ジャンプ台／バンパー | 40 ／ 35 ／ 25 |

- 段階（砥石ゲージ）：赤 〜14・橙 15〜・黄 25〜・緑 40〜・青 60〜・白 80〜・紫 100〜
- **C に上限はない**（v1.75 で上限 150 を廃止。虹はチャクラ解放を持っているときだけ C 160〜で付く）
- **見せ方**
  - パックの本体を段階の色にする。**パックの枠は黄色で固定し、一番上のレイヤーで必ず描く**（陣地の赤・青と混ざっても、どれがパックか必ず分かる）。
  - 自分のトレイに小さな砥石ゲージ（7段）。
  - 数字のポップは **段階が上がった時だけ**「C 60」をその色で（毎回は出さない）。

## 3. トリック値（狙って出せる4つだけ・足し算）
| ゴールの仕方 | 値 |
|---|---|
| バンク（最後の自分の打撃のあと壁に当たって入る。2回以上は +0.4） | +0.2 |
| ポスト（ポストに当たって入る） | +0.5 |
| 空中（ジャンプ台で跳んだまま入る） | +0.3 |
| ロング（自陣から、だれにも触られず直接入る） | +0.2 |

- 条件を満たした瞬間に、パックの軌跡に印（バンク＝壁の火花、空中＝影の輪 など）を付けて、入る前から「乗っている」と分かるようにする。
- 4秒ルールで敵の陣地が爆発：C × 1（トリック・ラリーなし、最低ダメージは適用）。

## 4. ラリー倍率
- 1 ＋ 0.1 × 往復数（速さ200以上で交互に打った回数）、上限【×3】。点が入るとリセット。

## 5. ゴールの表示と手応え（#9）
- ゴールの瞬間に Balatro 風に「60 × 1.2 × 1.8」→「＝ 130」と大きく出し、HP ゲージが減る。
- **ダメージの大きさ（敵の最大 HP に対する割合）で手応えを段階的に上げる**：ヒットストップ・画面の揺れ・フラッシュ・効果音の重さ。
  - 〜20%：ふつうのゴール／20〜50%：強／50%〜：特大／とどめ：特別な演出（記号の雨や撃破音）。
- 初めて 1K・1M・1B を超えた時は、桁の演出（数字が膨らんで弾ける）。

## 6. インフレ（5周目までは緩やか → 6周目から指数関数）
- **数字の表記**：1,234 → 12.3K → 4.56M → 7.89B → 1.23T → 以降 aa, ab …。ポップの文字の大きさは桁数で大きくなる。
- **敵の HP**：最初のザコ 100・最初の強敵 180・NULL 600。エンドレスは
  - **L1〜L5：1周ごとに【×1.35】**（緩やか。L1 のザコは 150）
  - **L6〜：1周ごとに【×2.2】**（指数関数）
  - 強敵の HP はザコの【×1.8】。
- **C は周回で伸びない**（v1.74 で研ぎを廃止。段階の境目も固定）。6周目以降のインフレについていくのは、×系を重ねたビルドと最低ダメージ（8%）。
- **自分の伸び**：パークの Lv の伸びも「最初は小さく、重ねるほど加速」に揃える（下の9）。序盤は＋系で少しずつ、×系は Lv が上がるほど急に伸びる＝6周目以降のインフレについていくのは ×系を重ねたビルド。
- 報酬の1枚は必ず「×系」か「＋C 系」から出す。

### 伸びの目安（1本あたりのダメージ）
- ふつう：パークが少し噛み合う（強打・スマッシュ混じり、ラリー4往復・トリック1つ）
- 噛み合った：その周回で取れる最大級（パリィ／スマッシュ＋トリック＋長いラリー＋×系）
- パークの数：L0 の終わりで約5個（スタート1＋報酬2＋ボス後1〜2）、以降1周ごとに +1

| 周回 | ザコ HP | 強敵 HP | ふつう | 本数（ザコ／強敵） | 噛み合った | 本数 |
|---|---|---|---|---|---|---|
| L0 | 100 | 180 | 50 | 2／4 | 190 | 1／1 |
| L1 | 150 | 270 | 80 | 2／4 | 300 | 1／1 |
| L2 | 200 | 360 | 110 | 2／4 | 500 | 1／1 |
| L3 | 270 | 490 | 150 | 2／4 | 800 | 1／1 |
| L4 | 370 | 660 | 210 | 2／4 | 1.3K | 1／1 |
| L5 | 500 | 900 | 290 | 2／4 | 2.2K | 1／1 |
| L6 | 1.1K | 2K | 600 | 2／4 | 4.5K | 1／1 |
| L7 | 2.4K | 4.3K | 900 | 3／5 | 10K | 1／1 |
| L8 | 5.3K | 9.6K | 1.5K | 4／7 | 25K | 1／1 |
| L10 | 26K | 46K | 4K | 7／12（最低ダメージ 8% で 13 本が上限） | 150K | 1／1 |
| L12 | 124K | 224K | 10K | 13 本（最低ダメージ頼み） | 1M | 1／1 |

- 5周目までは「ふつう」でもザコ2本・強敵4本が続く＝ゆっくり育つ時間。噛み合ったビルドは1本で倒せる爽快さ。
- 6周目から敵が急に伸び、×系を重ねていない「ふつう」は本数が増えてライフが削られる。噛み合ったビルドは数字がどんどん大きくなる（クッキークリッカーの伸び）。

## 7. 敵の強さ（POWER）
- 戦力ポイントの予算で「HP +20%」を 2pt で買える（ザコは HP 寄り、強敵は技寄り）。
- POWER は上限 10000 をなくし、HP と同じように指数関数で伸ばして、同じ表記（K・M…）で出す。

## 8. 今あるものの置きかえ
- ギリギリ王：「次の得点が2点」→「次のダメージ ×2」（実装済み）

## 実装メモ（v1.68）
- 本体（`site/index.html`）に足したのは差し込み口 `RULE.ev('jump'|'boost', 置物)` だけ（ジャンプ台・加速床にパックが触れたとき）。そのほかは `hit / postHit / bumperHit / explode / superFire / parryFire / serve / goal / render3D` を rogue.js で包んで取っている。
- HP は `RUN.hp / RUN.hpMax`。本体のボス処理（段階・台の傾き・撃破）には HP の割合を 3 段階（66%・33%）に直して渡している。ライフは `RUN.life`（本体の点数・ライフは使わない）。
- 画面：上の帯に敵の名前・HP ゲージ（減った分は白く残って縮む）・強さ、自分のトレイにライフ（ハート7）と C の砥石ゲージ、パックの枠（黄色固定・一番上の 2D レイヤー）と、トリックの印（枠のまわりの小さな四角）、ゴールの瞬間に「C × トリック × ラリー（× パーク）」→「＝ ダメージ」。
- 敵の強さ（POWER）は、戦力ポイントの指数 × HP（上限なし・K／M… 表記）。HP は予算 2pt で +20%（ザコはパーク予算の半分、強敵は余りの3割で買う）。
- NULL：HP 600、66%・33% で段階が変わる。パリィ球は C 80 にまかせる（特別な倍率なし）。
- 敵の強化パーク（ハード・ビッグ・ワイド）はそのまま（ゴールしやすさに効く）。

## 9. C システムのパーク（5周目まで緩やか・重ねるほど加速する数値）
Lv の伸びの型：
- **＋型**：Lv ごとに同じだけ足す（序盤向き。インフレには追いつかない）
- **×加速型**：Lv1 ×1.3 → Lv2 ×1.6 → Lv3 ×2 → Lv4 ×3 → Lv5 ×4.5 →（以降 ×1.5 ずつ）。5周目くらいまでは控えめ、6周目以降の主役。

| 名前 | 種類 | 効果（Lv1 → 重ねたとき） | 弱点 |
|---|---|---|---|
| スマッシュ職人 | ＋C | スマッシュの C +15/Lv | — |
| 底上げ | ＋C | すべての当たりの C +6/Lv | v1.78〜 |
| 跳躍の極意 | ＋C | ジャンプ台の C +12/Lv・空中 +0.1/Lv | — |
| 逆境の気 | ＋C | ライフ3以下で C +10/Lv | — |
| 蓄気 | ＋C | 自陣で持つ間 1秒ごと C +8/Lv | 4秒ルール |
| 反撃の型 | ×C 加速型 | パリィの C ×1.3 → ×1.6 → ×2 → ×3 … | — |
| バンク名人 | ＋倍率 | バンク +0.2/Lv | — |
| ポスト狙い | ＋倍率 | ポスト +0.3/Lv | — |
| 速攻 | ＋倍率 | 3往復以内のゴール +0.5/Lv | — |
| 長期戦 | ＋倍率 | ラリー上限 +0.5/Lv | 5往復未満は ×0.85 |
| 紫電 | ×倍率 加速型 | 紫の時 ×1.3 → ×1.6 → ×2 → ×3 → ×4.5 … | v1.78 で紫以外の ×0.85 の罰を撤廃（紫以外は ×1.0） |
| 研ぎ澄まし | 発動 | C が白以上でパック 15% 速く・敵のバンパーを貫く（Lv2〜 速さ +10%/Lv） | — |
| なまくら返し | 発動 | 赤〜橙でゴールすると次の打撃 C +30/Lv | — |
| 気の重ね | 上乗せ | パリィで C を置きかえず加算（Lv2〜 加算分 ×1.2/Lv） | ふつうの打撃の C が半分 |
| 連撃 | 上乗せ | 自分が触るたび +4/Lv を足していく | — |
| 吸気 | 回復 | 敵の HP の 50% 以上を1本で削るとライフ +1 | — |
| 余韻（レア） | 持ち越し | ゴール時 C の 30% を次のパックへ（Lv ごと +15%、上限 75%） | — |
| チャクラ解放（レア） | 発動 | C がそのラリー中は下がらない（弱い打撃で上書きしても最大値を保つ）。紫の先に虹（C 160〜で虹。虹はダメージ ×1.3） | v1.77 でリワーク |
| 増幅（レア） | ×倍率 加速型 | すべてのダメージ ×1.3 → ×1.6 → ×2 → ×3 … | — |
| 侵食（レア） | ×倍率 | GUARD が溜まらなくなりブレイクしない代わりに、敵マレットへの打撃が C ×25%（Lv ごと +15%、上限 85%）の即ダメージになる。倒し切り可 | v1.76〜 |

### 組み合わせの計算例（噛み合ったビルド）
- **L2**：スマッシュ職人 Lv3（C 60+45=105・紫）・バンク・ラリー8（×1.8）・紫電 Lv1（×1.3）
  → 105 × 1.2 × 1.8 × 1.3 ＝ **約 295**（ザコ 200 を1本）
- **L5**：上に 紫電 Lv3（×2）・増幅 Lv1（×1.3）・ラリー12（×2.2）・ポスト狙い Lv1（ポスト +0.8）
  → 105 × 1.8 × 2.2 × 2 × 1.3 ＝ **約 1.1K**（強敵 900 を1本）
- **L8**：紫電 Lv5（×4.5）・増幅 Lv3（×2）・反撃の型 Lv3 でパリィ C 80×2 = 160・ポスト・ラリー15
  → 160 × 1.8 × 2.5 × 4.5 × 2 ＝ **約 6.5K**（強敵 9.6K を2本）

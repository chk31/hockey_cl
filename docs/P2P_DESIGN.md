# オンライン対戦（P2P）設計

## 方式
- **ホスト権威型**。ホスト端末が物理・ルール・CPUなしの対戦を全て計算し、ゲストは入力送信と描画のみ。
- 接続：PeerJS（WebRTC DataChannel）。ピアID＝`aihockey-<ルームコード>`（数字4〜6桁）。
- **ホスト＝1P（下側）、ゲスト＝2P（上側）**。ただし**ゲスト端末では表示を180°反転**し、自分が下に来るようにする。

## 画面反転（ゲスト）
- フラグ `viewFlip`（ゲストのみ true）を追加。
  - `base()`：最後に論理座標を (FW−x, TL−y) へ反転する変換を掛ける。
  - `toL()`：逆変換の結果を反転して返す。
  - 3Dカメラ：`cam.up` を反転（縦なら (0,0,1)、横なら (−1,0,0)）。
  - `frame(i)`：ゲストでは i を入れ替えて、自分の UI が正立するようにする。

## 通信チャネル
PeerJS の `DataConnection` を2本張る（または1本で `reliable` を使い分け）。

| チャネル | 設定 | 用途 |
|---|---|---|
| `state` | `reliable:false`（不可なら reliable でも可） | ホスト→ゲスト スナップショット、ゲスト→ホスト 入力 |
| `event` | `reliable:true` | 開始・ゴール・アイテム取得・設置・エフェクト・終了・切断通知 |

メッセージは JSON（必要ならキーを短縮）。全メッセージに `v`（プロトコル版）を入れる。

### ゲスト → ホスト
```js
{t:'in', seq, x, y, down:true}          // マレット目標（論理座標・ゲストは反転済みで送る）60Hz
{t:'sel', slot}                          // アイテム選択（ドラッグ開始 or タップ）
{t:'put', slot, x, y}                    // 設置確定
{t:'cancel', slot}
{t:'ping', ts}
```
### ホスト → ゲスト
```js
{t:'snap', tick, st, goalT, live, ts,     // 30Hz
  pk:[x,y,vx,vy,air,airT,hold,side,boom,inMud],
  m:[[x,y],[x,y]], sc:[a,b], it:[[...],[...]], box:[[on,x,y,cd],[...]],
  pl:[[id,type,x,y,o,age,life,dx,dy],...], arm:[...], gh:[...] }
{t:'fx', k, x, y, s, col, extra}          // addFx を転送（ゲストでそのまま再生）
{t:'juice', sh, stop, a, fl, col}
{t:'snd', name, args}                     // beep/seq/slide/noise の呼び出し
{t:'start'} {t:'goal', scorer} {t:'over'} {t:'pong', ts}
```

## 同期・遅延対策
- ゲストは受信スナップショットを**約100ms遅れで補間表示**（2つの間を線形補間、パックは速度で軽く外挿）。
- ゲスト自陣（上半分）のパックは「いまホストに届く入力が当たる位置」まで最新スナップショットから先読みする。v1.38 から先読みは壁の反射・摩擦・ゴール口を含めて計算（`gPredict`）。相手陣地の補間との切り替えは中央線の前後240の幅で smoothstep し、さらに時間でならす（`NET.gw`）。予測のずれは約70msで戻し、1フレームで戻す量は90までに抑える。
- **自分のマレットはローカル即時表示**（予測）。ホストの値とずれが大きい（>40）ときだけ寄せる。
- スロー（アイテム選択中）はホストの `ts` に従う。ゲストの選択もホストが猶予タイマーを管理。
- エフェクトはホストの `addFx/juice/音` 呼び出しをフックして `fx/juice/snd` イベントで転送。
  ゲスト側では `FX STYLE/COLOR/LEVEL` を**自分のテーマで**再生（色は自分の設定）。
- 入力は `seq` 付き。古いものは捨てる。

## ロビー UI（最小限）
- タイトルの1P側パネルに `ONLINE` ボタン追加 → パネルに `HOST` / `JOIN` の2ボタン。
  - HOST：ランダム4桁コードを大きく表示して待機（点滅）。接続されたら自動で開始。
  - JOIN：ドット風の数字キーパッド（0-9・消去・OK）で入力。
- 接続中・切断は色と点滅で示す。切断時は「DISCONNECTED」1語を出してタイトルへ戻る。
- 対戦中、画面隅に小さく RTT(ms) を出してよい（任意）。
- ONLINE 中は2P側の画面パネルは非表示（各端末1人）。

## エラー処理
- PeerJS `error`（`unavailable-id` ならコード再生成、`peer-unavailable` は JOIN 失敗表示）。
- 3秒間スナップショットが来なければ切断扱い。
- ICE 設定は `PEER_CONFIG` 定数にまとめ、TURN を後から追加できるようにする。

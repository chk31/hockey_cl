BASIC基本のシステム

打ち合ってゴールを決める

  • 自分の陣地（手前半分）を指でなぞると、マレットがついてきます。
  • パックを打って、相手のゴール（奥）に入れると 1点。
  • 先に 7 点取ったほうの勝ち。
  • 速く振り抜くほど強い球になります。強打は派手なエフェクトが出ます。
打ち合い → ゴール

モード：CPU（よわい／ふつう／つよい）、2P（1台を2人で）、ONLINE（2台で対戦）。画面下の II ボタンで一時停止できます。

4秒ルール

  • 自分の陣地にパックを 4秒 置いたままにすると、爆発して 相手の点 になります。
  • 残り3秒からパックのまわりにカウントが出ます。早めに打ち返しましょう。
カウントが 0 になると爆発

アイテムボックス

  1. 自分の陣地にときどき ボックス が出ます。パックを当てるとアイテムをもらえます（最大 2 つ）。
  2. 画面下のアイテム欄から、指で 自分の陣地へドラッグ して置きます。置く場所は指の少し先に表示されます。
  3. 置いたアイテムはしばらくすると消えます。1人 3 つまで置けます。
ボックス → アイテム欄 → ドラッグして設置

サーブ直後（パックが動き出すまで）はアイテムを使えません。ボックスを取ると約10秒後に次のボックスが出ます。

PARRYパリィ

当たる直前に指を離して、時間を止める

  1. 相手の速い球が来たら、マレットを構えたまま待ちます。
  2. パックが当たる 直前（0.1秒以内）に指を離す と成立。「キュイーン」と鳴って 1秒間 時間が止まります。
  3. 止まっている間に、自分の陣地に指を置いて 引っ張って狙い、離すと引っ張った反対の方向へ弾きます。
  4. 弾いた球は加速しながら飛んでいきます（来た球の1.2倍、2160〜2600）。
停止 → 引っ張って狙う → 発射

成立する条件

  • 直前にパックに触ったのが 自分ではない（相手の打球など。自分の打球が戻ってきたものは不可）。
  • パックが 速い（速さ 1000 以上）。

止まっている間に指を置かなければ普通に跳ね返る向きへ、時間切れのときはその時の向きへ弾きます。スーパーシュートの球もパリィで返せます（スタンしません）。CPU はパリィを使いません。受付時間などは開発者画面で変えられます。

ITEMSアイテム

JUMPジャンプ台

  • 上を通ったパックが 約1秒宙に浮き、マレットや設置物を飛び越えます。
  • 着地の瞬間にドンと衝撃。相手の守りの上を越えてゴールを狙えます。
自分の打球を跳ばして CPU の上を越える

BOOST加速床

  • 上を通ったパックを、床の矢印の向きへ 一直線に加速（最大 2600）。
  • 矢印は置いた位置から相手ゴールの方を向きます。打球のコースに置くと一気にゴールへ。
加速床を通して一気にゴール

BUMPERバンパー

  • 当たったパックを 強く跳ね返す 柱です（1.25倍の勢い）。
  • ゴール前に置けば守りに、ほかの場所なら跳ね返りを使った攻めにも。
ゴール前で相手の球を跳ね返す

SLIMEスライム

  • 上を通ったパックが 大きく減速 し、ネバネバがつきます。
  • マレットも沼の中では遅くなります。相手の速い球をここで止めましょう。
速い球が沼で止まる

SUPERスーパーシュート

  1. アイテム欄の キノコをタップ すると、マレットが青いオーラで強化されます（置く必要はありません）。
  2. 強化中にパックに触れると、スローになって 構え に入ります（両者とも動けません）。
  3. 指を引っ張って狙い、離すと引っ張った反対の方向へ 最高速（2600） で発射。2.5秒で自動発射。
  • 青いオーラの球を受けた相手は 1.5秒スタン し、球は 減速して、必ず打った側のコートへ跳ね返ります。追い打ちのチャンス！
  • 設置物を壊します（バンパー・スライムは効果のあと、加速床は効果なしで壊れる。ジャンプ台は壊れない）。
強化 → 構え → 発射 → スタン → 追い打ち
